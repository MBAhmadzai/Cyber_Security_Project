# CyberSecurityProject

## Overview
This project was developed as part of the Fall term 19/20 coursework at Moscow Institute of Physics and Technology (MIPT) focusing on cybersecurity.

## Objectives
- To explore key concepts in cybersecurity
- To implement security measures in real-world scenarios
- To analyze vulnerabilities and propose solutions

## Features
- Secure authentication and access control
- Encryption and data protection mechanisms
- Threat analysis and mitigation strategies

## Technologies Used
- Programming Languages: Python, C++
- Security Tools: OpenSSL, Wireshark
- Frameworks: Flask (for web security applications)

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/CyberSecurityProject.git
   ```
2. Navigate to the project directory:
   ```sh
   cd CyberSecurityProject
   ```
3. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```

## Usage
Run the main application:
```sh
python main.py
```
